# متابعة مستندات الإثبات

تمت إضافة طبقة متابعة تشغيلية فوق ملف مستندات الإثبات للعقارات محل تحليل مؤشرات السيطرة.

## بيانات المتابعة لكل مستند
- الجهة أو المسؤول عن المتابعة.
- تاريخ الاستحقاق.
- الأولوية: منخفضة / متوسطة / عالية.
- حالة المتابعة: لم يبدأ / تحت المتابعة / بانتظار جهة خارجية / مكتمل.
- آخر إجراء وتاريخه.

## التنبيهات
يعد المستند متأخرًا عندما تكون حالته غير «متوفر»، ومهمة المتابعة غير مكتملة، ويوجد تاريخ استحقاق سابق لتاريخ اليوم. تعرض صفحة مؤشرات السيطرة عدد أيام التأخير، وتجمع لوحة مستندات الإثبات المهام المفتوحة والمتأخرة والأولوية العالية.

## التخزين
تُحفظ بيانات المتابعة داخل `__propertyControlAnalysis.evidenceChecklist` في سجل العقار نفسه، ولا يتم إنشاء قاعدة مهام أو مرفقات موازية.

## لوحة التحول المحاسبي
عند وجود مهام إثبات متأخرة يظهر تنبيه في لوحة التحول المحاسبي مع عدد المتأخرات ورابط إلى لوحة مستندات الإثبات.
