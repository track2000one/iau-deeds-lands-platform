# سجل تاريخ متابعة مستندات الإثبات

تمت إضافة سجل زمني داخل كل عنصر من `evidenceChecklist` في `__propertyControlAnalysis`.

## ما يسجله النظام
- إنشاء مهمة متابعة لأول مرة.
- تغيير حالة المستند.
- تغيير الجهة أو المسؤول.
- تغيير تاريخ الاستحقاق.
- تغيير الأولوية.
- تغيير حالة المتابعة.
- تسجيل آخر إجراء.
- رفع أو ربط مستند.
- إقفال المهمة.
- ملاحظات متابعة يضيفها المستخدم يدويًا.

## أحداث النظام المشتقة
يعرض الخط الزمني كذلك نقاطًا زمنية مشتقة من تاريخ الاستحقاق: دخول نطاق 7 أيام، بدء التأخير، والانتقال إلى المستوى الحرج. وتظل هذه النقاط قابلة للاستنتاج حتى بعد إقفال المهمة، استنادًا إلى تاريخ الإقفال المحفوظ.

## العرض
- صفحة مؤشرات السيطرة تعرض خطًا زمنيًا لكل مستند مع إضافة ملاحظات متابعة جديدة.
- لوحة متابعة مستندات الإثبات تعرض عدد أحداث كل مهمة وآخر حدث.
- تقرير الطباعة يتضمن ملخص السجل الزمني لكل مهمة.
